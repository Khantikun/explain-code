# แผนยุบปุ่มเปลี่ยนโหมดให้เหลือเฉพาะดันเจี้ยน 2D และนำจุดเด่นของ PRIMM มาปรับใช้ในดันเจี้ยน

## 1. เป้าหมาย (Goal)
1. **ลบปุ่มเปลี่ยนโหมด** ระหว่าง `โหมด PRIMM คลาสสิก` และ `โหมดดันเจี้ยน 2D` ใน [TopicDungeonArena.tsx](../../app/components/dungeon/TopicDungeonArena.tsx) ให้ผู้ใช้เล่นผ่าน **โหมดดันเจี้ยน 2D** เป็นประสบการณ์หลักเพียงโหมดเดียว
2. **คัดเลือกเฉพาะกลไกที่ดีที่สุดของ PRIMM** (`PracticeArena.tsx`) มาหลอมรวมเข้ากับระบบ RPG ในดันเจี้ยนอย่างพอดี เพื่อยกระดับทั้งความสนุกและคุณภาพการเรียนรู้

## 2. เปรียบเทียบ: PRIMM คลาสสิก มีอะไรที่ ดันเจี้ยน 2D ยังไม่มี?

| องค์ประกอบใน PRIMM (`PracticeArena.tsx`) | สถานะในดันเจี้ยน 2D ปัจจุบัน | ควรเอามาปรับใช้แค่ไหน? |
| :--- | :--- | :--- |
| **1. Predict & Run (พิมพ์ทายผล + เทียบผลรัน)** | มีเฉพาะเลือกช้อยส์ 1-4 | **ปรับใช้บางส่วน** (อยู่ในสกิลส่อง Output + ปรับเป็นด่าน Modify) — ไม่ต้องให้พิมพ์ทุกข้อเพราะจะช้า |
| **2. Interactive Line-by-Line Trace (`topic.steps`)** | มีเฉพาะตอนกดใช้สกิล Trace Lens (2 MP) | **✅ ควรนำมาใช้ 100%** ในแผง "คัมภีร์โค้ดประจำด่าน" ด้านขวา เพื่อให้ผู้เล่นฝึกไล่โค้ดก่อนเดินชนมอนสเตอร์ |
| **3. Quiz Block Model 12 ช่อง** | **มีแล้ว** ใน `BattleOverlay` (Multi-Phase) | คงไว้ตามเดิม (ดันเจี้ยนทำได้สนุกกว่าอยู่แล้ว) |
| **4. Modify Challenge (`topic.modifyChallenge`)** | **ยังไม่มีเลย** | **✅ ควรนำมาใช้แบบเฉพาะจุด** เป็น **"แท่นซ่อมมนตร์ (Modify Chest/Altar)"** หรือ **เฟสพิเศษหลังปราบมอนสเตอร์** |
| **5. AI Free Explanation (`/api/interrogate`)** | **ยังไม่มีเลย** | **⚠️ นำมาใช้เฉพาะด่านบอส (Optional Bonus)** เพื่อไม่ให้ขัดจังหวะการเล่นด่านปกติ |

## 3. ควรเอามาปรับใช้แค่ไหน และจะดีขึ้นยังไง?

> **หลักการสำคัญ:** ไม่ควรยกฟอร์ม PRIMM ทั้ง 5 ขั้นตอนมาใส่ตรงๆ เพราะจะทำให้เกมเดินช้าและน่าเบื่อ ควรแปลงเป็น **"กลไก RPG 2–3 จุด"** ที่เสริมการเรียนรู้โดยยังคงความสนุกแบบดันเจี้ยน

### สิ่งที่จะดีขึ้นอย่างชัดเจน:
1. **เปลี่ยนจาก "อ่านและเดาช้อยส์" → "เข้าใจลำดับการทำงานและแก้โค้ดได้จริง"**
   - การเพิ่ม **Interactive Trace (`topic.steps`)** ที่คัมภีร์ด้านขวา ช่วยให้ผู้เล่นที่ยังไม่แม่นสามารถกดดูการทำงานทีละบรรทัดก่อนเดินเข้าสู้ได้ (ช่วยลดการเดาสุ่ม)
   - การเพิ่ม **Modify Challenge** ช่วยวัดทักษะการลงมือแก้โค้ดจริง (`runCodeByLanguage`) ซึ่งเป็นจุดแข็งที่สุดของ PRIMM ที่เกม Quiz ทั่วไปไม่มี
2. **UI สะอาดตาขึ้น ไม่มี 2 ระบบซ้อนกัน**
   - ผู้ใช้ไม่งงว่าควรเล่นโหมดไหน และข้อมูลคะแนน/XP ไหลผ่าน Pipeline เดียวกันทั้งหมด
3. **จังหวะเกมกระชับ ไม่ยืดเยื้อ**
   - ด่านทั่วไปสู้มอนสเตอร์ + กดดู Trace ได้อิสระ + เลือกทำ Modify โบนัสได้ (หรือบังคับเฉพาะด่านบอส)
