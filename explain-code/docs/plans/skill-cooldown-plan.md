# แผนพัฒนาระบบคูลดาวน์สกิลประจำตัวละคร (Skill Cooldown System)

## 1. วัตถุประสงค์ (Goal)
เพิ่มระบบ **คูลดาวน์สกิลแบบนับจำนวนเฟส (Phase-based Cooldown)** ให้กับสกิลทั้ง 3 ระดับของทุกตัวละคร เพื่อป้องกันไม่ให้ผู้เล่นที่ตอบถูกและได้รับ MP คืน (โดยเฉพาะ **นักเวทลูป** ที่ได้ +2 MP หรือสกิล **1-2 MP** ของคลาสอื่นๆ) สามารถกดสแปมสกิลเดิมซ้ำได้ทุกเฟสติดต่อกัน ทำให้การเลือกจังหวะใช้สกิลมีความหมายและสมดุลมากยิ่งขึ้น

---

## 2. การออกแบบคูลดาวน์ตามระดับสกิล (Cooldown Tiers)

- **สกิล Tier 1 (1 MP):** คูลดาวน์ **1 เฟส** *(ใช้เฟส 1 -> ล็อกในเฟส 2 -> กลับมาใช้ได้ในเฟส 3)*
- **สกิล Tier 2 (2 MP):** คูลดาวน์ **2 เฟส** *(ใช้เฟส 1 -> ล็อกในเฟส 2, 3 -> กลับมาใช้ได้ในเฟส 4)*
- **สกิล Tier 3 (3-4 MP):** คูลดาวน์ **3 เฟส** *(ใช้เฟส 1 -> ล็อกในเฟส 2, 3, 4 -> กลับมาใช้ได้ในเฟส 5)*

### กลไกป้องกันการรีเซ็ตคูลดาวน์ (Anti-Spam Flow)
1. เมื่อกดใช้สกิลในเฟสปัจจุบัน ระบบจะล็อกสกิลนั้นในเฟสนี้ (`usedSkillIds`) และกำหนดค่า `skillCooldowns[skill.id] = skill.cooldownPhases`
2. เมื่อตอบถูกและกดเข้าสู่เฟสถัดไป (`handleNextPhase`):
   - สกิลที่ **เพิ่งกดใช้ในเฟสที่จบลง** จะเข้าสู่เฟสถัดไปด้วยค่าคูลดาวน์เต็ม (`cooldownPhases` เฟส)
   - สกิลอื่นที่ติดคูลดาวน์อยู่ก่อนหน้า จะถูกลดคูลดาวน์ลง `1` เฟส
3. เมื่อตอบผิดและกดลองใหม่ในเฟสเดิม (`handleRetryPhase`):
   - ระบบ **ไม่รีเซ็ต** `usedSkillIds` และ `skillCooldowns` เพื่อป้องกันการจงใจตอบผิดเพื่อล้างคูลดาวน์

## 3. ไฟล์ที่จะแก้ไข (Proposed Changes)

1. **`explain-code/app/lib/dungeon/sprites.ts`**
   - เพิ่มฟิลด์ `cooldownPhases: number` ใน `HeroSkillDef`
   - กำหนด `cooldownPhases` (`1`, `2`, `3`) ให้กับสกิลทั้ง 12 ท่าของฮีโร่ทั้ง 4 ตัวละคร

2. **`explain-code/app/components/dungeon/BattleOverlay.tsx`**
   - เพิ่ม state `skillCooldowns: Record<string, number>`
   - เช็กคูลดาวน์ก่อนอนุญาตให้กดใช้สกิล
   - อัปเดตการลดคูลดาวน์ใน `handleNextPhase()`
   - แสดงป้ายสถานะ `⏳ CD X เฟส` บนปุ่มสกิลเมื่อติดคูลดาวน์ และแสดงระยะคูลดาวน์พื้นฐาน (`CD X`) เมื่อพร้อมใช้

3. **`explain-code/app/courses/page.tsx`**
   - แสดงป้ายคูลดาวน์ `⏳ CD {skill.cooldownPhases}` คู่กับ `{skill.mpCost} MP` บนการ์ดเลือกตัวละครทั้ง 4 ใบ
