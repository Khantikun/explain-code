# MASTER DESIGN CHARTER: TACTICAL CODE-BATTLER (CODE DEPTHS)

## 1. วิสัยทัศน์และปรัชญาการออกแบบ (Design Philosophy)
* **ไม่ใช่ข้อสอบคอสเพลย์เป็นเกม:** การต่อสู้ไม่ใช่ระบบทวิภาค (Binary) เช่น "โค้ดถูก = ตีมอน / โค้ดผิด = โดนตี"
* **โค้ดคือเครื่องยนต์กลไกแห่งเวทมนตร์ (Code as Magical Engine):** โค้ดทำหน้าที่เป็นสคริปต์ความสามารถ (Ability Script) ที่ผลิตผลลัพธ์ในสนามรบจริง
* **มีต้นทุนและความเสี่ยง (Trade-offs & Resource Management):** ทุกตรรกะมีราคาที่ต้องจ่าย เช่น ลูปหลายรอบเพิ่มจำนวนฮิตแต่กิน Mana, เงื่อนไขสุ่มติดคริติคอลเพิ่มดาเมจแต่เสี่ยงเสียเลือด
* **การดวลตรรกะแก้ทาง (Script Dueling & Elemental Matrix):** มอนสเตอร์มีสคริปต์พฤติกรรมของตัวเองที่ผู้เล่นสแกนตรวจสอบได้ และผู้เล่นต้องปรับโค้ดเพื่อแก้ทางตรรกะของมอนสเตอร์

## 3. กฎเหล็กของระบบ (Non-Negotiable System Invariants)
1. ห้ามมีสถานะ Instant Kill หากโค้ดมีบั๊ก ให้แปลงเป็นสถานะการต่อสู้ เช่น Spell Fizzle (ดาเมจ 0) หรือ Overheat (ชาร์จค้าง 1 เทิร์น)
2. ทุกการเปลี่ยนแปลงโค้ดต้องกระทบต่อตัวเลขสถานะหรือเอฟเฟกต์ในสนามรบจริง
3. งดใช้อิโมจิในเอกสารและโค้ดทั้งหมดตามระเบียบระบบ
